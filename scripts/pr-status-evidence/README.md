# Working-status comparison driver

This isolated evidence branch checks out the exact source heads in `targets.json`, verifies their Git trees, and overlays two previously untracked test-only files. It never changes a tracked application file. The production timeline, LegendList, SVG branding primitive, stylesheet and `useTheme` hook render the captured interface. Conversation and working-state props are controlled by clearly labelled fixture controls; no native desktop or live provider run is claimed.

Each source runs once with normal Chromium motion preferences and once with reduced motion. The actual CSS animation runs continuously during capture. The fixture observes twenty positions over a full shimmer period, checks the shared timeline cadence and visible base color, and records four states in each mode: dark Thinking at 13px, dark Thinking at 18px, the unchanged semantic delivery icon at 18px, and light Thinking at 13px. The repaired state additionally requires the inline Synara SVG and relative mark sizing. Existing working-header wording and timer remain asserted.

The runner records source/tree/file Git identities, SHA256 hashes of every overlay and artifact, the immutable driver commit, original logs, and the actual Vitest and tee exits. An unsuccessful run remains unsuccessful. Failed recordings and partial screenshots are diagnostic artifacts only. GitHub artifacts are inspected and hash-verified before any image or clip is published to a PR. Playwright records the entire browser context at 1280×900; the fixture viewport is 800×560, so recorder padding may appear in the raw video. No imagery is generated or redrawn.
